# Between-session update · Discussion with Justin

The update is a short report for the therapist to read before the next appointment. It covers the tasks and observations the client chose to share. This is a fictional example.

## What Maya recorded

| Task | Record | Chosen for the update |
| --- | --- | --- |
| Read the material from last session | Marked complete | No |
| Note a schedule change | On Tuesday a project was moved, and Maya changed her plans that day | No |
| Log three walks | Two walks logged. In a progress note, Maya said she skipped one planned walk because she worked late | Both walk records and the progress note |
| Bring up next time | Talk about how last-minute changes affect after-work plans | Yes |

When assigning the walks, Dr. Lee added: “I’d like to know what gets in the way when plans change.”

## Questions for the meeting

1. Looking only at the shared records, which detail would change what you ask first in the next session? Which line of the brief could you leave out?
2. When you assign something to track, would you write one sentence about what you want to learn? What would you write for the walks?
3. When someone shares two records against a plan of three, what do you need to see in the inbox? Would you include the count, the reason they reported or both?
4. Which task would you use first in your own workflow? Is there something you commonly ask people to bring back that these templates miss?
