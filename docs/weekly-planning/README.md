# Weekly Planning

Use this area to make each week's work and Thursday meeting preparation easy to see in one place.

## Weekly workflow

1. Copy [the weekly template](weeks/TEMPLATE.md) to `weeks/YYYY-MM-DD.md`, using the Monday date for the week.
2. At the start of the week, agree on the main goal, research tasks, owners, and expected outputs.
3. For each research task, link the related record in `docs/research/weekly/`. Keep research details and source citations there.
4. Before Thursday's meeting, write the questions for instructors or university staff and state what clarification or decision the team needs.
5. After the meeting, record outcomes, unresolved questions, owners, and due dates. Link to the detailed meeting notes in `docs/meetings/team/` or `docs/meetings/stakeholders/`.
6. Create a GitHub issue for follow-up work that needs tracking across weeks, and link it from the weekly plan.

Weekly plans are a short coordination page, not a replacement for research records or meeting notes. Update the same file after the meeting so the plan and outcomes stay together.
