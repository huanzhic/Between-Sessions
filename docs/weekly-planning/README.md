# Weekly Planning

Keep one file per week in `weeks/`. Copy [the template](weeks/TEMPLATE.md) to `weeks/YYYY-MM-DD.md`, using that week's Monday date.

Each weekly record is the single place to coordinate the week's todo, research questions and findings, Thursday meeting preparation and notes, decisions, and follow-up. This avoids maintaining separate planning, research, and meeting files for the same week.

Use the [source index](../research/sources/source-index.md) to register each source once. Refer to its stable ID from any weekly record that uses it. Keep research evidence, the team's interpretation, and unresolved assumptions clearly distinguished.

Only include meeting summaries and research material approved for this repository. Do not add private correspondence, meeting recordings, real client data, or identifiable sensitive research data.
