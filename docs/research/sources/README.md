# Sources

Use the [source index](source-index.md) as the single catalog for sources the team plans to read or has reviewed.

## Add and reuse sources

- Check the index before adding a source. Add each source only once.
- Assign the next stable ID (`S001`, `S002`, etc.); do not renumber IDs when entries are added or reordered.
- Include enough citation information to find the source again: title, author(s), year, publication or organization, and DOI or stable URL.
- Track reading status and the dated weekly research folders that cite the source (for example, `docs/weeks/2026-10-12/`).
- Put week-specific reading notes and synthesis in that week's `research.md`, not in duplicate source copies. If substantial source-specific notes are needed, link a separate notes file from the index.
- When a source is superseded or found not useful, keep its entry and update its status or note; this preserves the research trail.

## File and data limits

Prefer citations and stable links. Store PDFs or other full texts only when copyright, license, and course rules allow it. Do not add private correspondence, confidential partner materials, or identifiable sensitive data.
