# Research Records and Sources

Research notes and source citations serve different purposes:

- The dated weekly record in [`docs/weekly-planning/weeks/`](../weekly-planning/weeks/) captures what the team set out to learn that week, how it searched, what it found, limitations, and follow-up questions.
- [`sources/source-index.md`](sources/source-index.md) is the reusable catalog of sources. Each source is entered once with a stable ID (such as `S001`) and referenced from every relevant weekly record.

Before adding a source, search the source index to avoid duplicates. Keep evidence, team interpretation, and unvalidated assumptions distinct. There is no separate topics directory or research index at this stage; the weekly records and source catalog are the current lightweight system.

Do not store real client records, therapy notes, EHR data, or identifiable sensitive research data in this repository. Prefer citations and stable links; include full-text files only when copyright, license, course rules, and required approvals allow it.
