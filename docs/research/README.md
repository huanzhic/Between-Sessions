# Research Records

This folder keeps a traceable record of what the team researches each week and the sources used. It is for research planning and synthesis; it does not imply that assumptions have been validated or that the project is clinically effective.

## Where things go

- `weekly/` — dated research records: questions, approach, sources reviewed, findings, limitations, and follow-up.
- `sources/` — one central source catalog with stable IDs so the team can find and reuse sources across weeks.

There is no separate topics directory or research index at this stage. Use dated filenames to find weekly records and the source index to find sources. Add a separate index only if the collection later becomes difficult to navigate.

## Workflow

1. Copy [the weekly research template](weekly/TEMPLATE.md) to `weekly/YYYY-MM-DD.md`.
2. Search the source index before adding a source, to avoid duplicate entries.
3. Add a new source once in [the source index](sources/source-index.md), assign the next stable ID (such as `S001`), and use that ID in every weekly record that cites it.
4. Keep findings, interpretation, and unresolved questions distinct. Link the week's record from its weekly plan and add Thursday questions there.
5. Update a weekly record when research continues; keep earlier dated records so the team can trace how understanding changed.

## Handling research material

Do not store real client records, therapy notes, EHR data, or identifiable sensitive research data in this repository. Store only research materials that have the required approval. Prefer citation details and links; include full-text files only when permitted by license and course policy. Do not upload private emails or meeting recordings.
